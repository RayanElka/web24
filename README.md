# Expense Tracker Prototype

An early expense tracker built for Web Development at AP University of Applied Sciences and Arts. The Express web app renders EJS views and stores entries in a local JSON file. The repository also contains an earlier TypeScript command-line exercise.

Run `npm ci`, then `npm start` from the repository root. Open http://localhost:3000. The web app writes changes to `json/gebruikers.json`.

The [later Expense Manager](https://github.com/RayanElka/Webontwikkeling-project-24-25) adds accounts and MongoDB storage.
